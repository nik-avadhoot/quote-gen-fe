Screen switches on the main path

This is the shortest path: an existing customer, one product, and the same person approving. Count what you actually do and compare. The target is for the whole quote to live on one page, with approval and sharing as states of that page.

How to judge each step

Mark a step Pass only when it meets all six tests. If it works but breaks one, mark it Hurdle. If you cannot finish it, mark it Fail.

Five-second ruleWithout hovering, you can tell what the next action is.
Your words, not the system'sLabels say customer, product, price, quote, send. No Batch, durable, governed, candidate or lineage.
One obvious primary actionExactly one button looks like the thing to press.
Stay in placeYou finish the task without changing screens or retyping a reference.
ForgivingMistakes can be undone. Warnings come before the click, not in a toast afterwards.
ConsistentThe same word and the same control mean the same thing on every screen.
