# PKGCanvas PNG brand kit

## Full wordmark

- `pkgcanvas-wordmark-primary-transparent.png` — default use on light backgrounds
- `pkgcanvas-wordmark-primary-light.png` — ready-made warm off-white background
- `pkgcanvas-wordmark-inverse-transparent.png` — inverse mark for dark backgrounds
- `pkgcanvas-wordmark-inverse-dark.png` — ready-made deep-slate background

## Compact PC mark

- `pkgcanvas-pc-primary-transparent.png` — compact mark on light or neutral surfaces
- `pkgcanvas-pc-primary-light.png` — browser favicon, app icon and avatar use
- `pkgcanvas-pc-inverse-transparent.png` — compact mark for dark UI surfaces
- `pkgcanvas-pc-inverse-dark.png` — ready-made dark app tile

## Brand colours

- Deep slate: `#1C2B3A`
- Amber-orange: `#D97B2E`
- Kraft connector: `#C39A6B`
- Warm off-white: `#FAF7F2`

Do not recolour the kraft connector amber. Preserve the clear colour distinction
between the connector and the `Canvas` lettering.
